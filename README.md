# bdix-nuvio-providers

Streams from BDIX-connected libraries, for [Nuvio](https://github.com/NuvioMedia/NuvioMobile).

The providers run on your device, so there is nothing to host and nothing to run.

Sources: CircleFTP · CTGMovies · Dflix(Dot) · DhakaFlix · ICC FTP · Nagordola

## Install

In Nuvio, go to **Settings → Plugins → Add repository** and paste:

```
https://raw.githubusercontent.com/ahnaf0014/bdix-nuvio-providers/main/manifest.json
```

Open any film or series and the streams are there. Each source has its own
on/off switch on the Plugins screen.

Nuvio needs a **TMDB API key** to look titles up — set one in Nuvio's settings
under TMDB. Without it, streams come back empty.
